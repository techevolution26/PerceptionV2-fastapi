# Stage 4E — Analytical Profile Foundation

Professional identity and the analytical profile are separate concepts. Professional identity is managed through the structured taxonomy flow; verification is a separate platform-review state; the analytical profile controls analytical scope and location context. Analytics access remains subscription-controlled in the current product.

Perception analytics now exposes topic, author professional role/verification state, engagement totals, daily activity, and aggregate audience country/professional-role breakdowns. Audience breakdowns are suppressed below five unique participants.

Comment sentiment, stance, semantic themes, language clustering, regional linguistic patterns, causal inference, prediction, and large-scale professional intelligence remain explicitly deferred.
